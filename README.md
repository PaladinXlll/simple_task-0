# Замер скорости загрузки

Консольная программа принимает ссылку на файл, выполняет 10 последовательных загрузок и дожидается полного ответа на каждый запрос. Во время загрузки в консоли отображается скорость. После завершения показываются среднее время запроса, общий объём полученных данных и последняя измеренная скорость.

## Простой запуск в Windows

Скачайте только файл [Task-0.exe](https://github.com/PaladinXlll/simple_task-0/blob/main/Task-0.exe). Клонировать репозиторий и устанавливать Python или библиотеки для этого способа не нужно.

Запустите `Task-0.exe` из папки, куда скачали файл. Введите адрес файла, когда программа попросит ссылку.

## Тестовая ссылка

Для проверки можно использовать большой TIFF-файл:

[https://data.source.coop/harvard-lil/smithsonian-open-access/media/nzp/NZP-1501-1JC.tif](https://data.source.coop/harvard-lil/smithsonian-open-access/media/nzp/NZP-1501-1JC.tif)

Файл большой. Десять последовательных загрузок могут передать около 0,5 GB данных и занять заметное время.

## Результаты и папки

Скачанный файл сохраняется в папку `files`, которая создаётся автоматически. Во время работы программы файл перезаписывается следующими пробами, поэтому НЕ открывайте его до завершения программы.

При каждом запуске папки `tmp` и `files` очищаются и создаются заново. Старые результаты из этих папок удаляются автоматически; вручную чистить их не нужно.

Скорость отображается в `MB/s`, общий объём — в `KB` и `MB`.

## Продвинутый запуск из исходного кода

Исходный код доступен в `script.py`. Чтобы запустить его напрямую, установите Python и зависимости:

```powershell
python -m pip install requests filetype
python script.py
```

После запуска введите собственную ссылку в консоль.

В `script.py` на строке 10 находится массив `links` с примерами адресов. Чтобы использовать ссылку из массива, замените ввод `link = input(...)` на `link = links[номер]` и разместите это присваивание после объявления массива. Индексы списка начинаются с нуля: для первого адреса используйте `links[0]`.
